# Адаптация скилла `perfectly-replicate-writing-skills` под русский язык (скорректированный план)

## Context

Скилл спроектирован под китайский и английский языки: пороги в символах/словах, списки маркеров — только английские, шкала оценки — китайская, метки измерений в шаблоне — китайские, русский в детекции отсутствует. Задача — адаптировать скилл для клонирования стиля русскоязычных авторов (автор бизнес-ТЗ 1С из `C:\WorkProjects\Райтек`) **без изменения базовой архитектуры** (5 фаз, 7+1 измерений, двойной вывод).

Ключевое решение (согласовано): **инструкции скилла остаются на английском** (экономия токенов), но **описывают правила русского языка**; модель читает/думает на английском, **пишет на русском**. Вывод (style card, persona, style prompt) генерируется **на русском**.

Подход: **чисто prompt-driven, без новых скриптов и зависимостей**.

**Скорректировки относительно предыдущего плана** (по замечанию пользователя, устранение двух методологических недостатков, связанных с ограничениями LLM):
- **Правка 1 (лемматизация):** LLM плохо справляются с точной лемматизацией больших текстов → вместо «лемматизируй» — инструкция **группировать словоформы вручную** + **сноска в Style Card**, что лексические метрики приблизительны; неизменяемые аббревиатуры (ТМЦ, СиМ, ТСД) не требуют лемматизации.
- **Правка 2 (Blind Test):** 200-300 слов для русского слишком мало (не видно структуру абзацев/синтаксиса) → тестовые тексты **500-700 слов** (≈3500-5000 символов), порог 70% оценивается на этом расширенном объёме.
