# Perfect Replicate Distillation Writing Skill

> **Клонирование стиля любого автора** путём глубокого анализа его текстов по 7+1 измерениям.

**Русскоязычная адаптация** скилла [Perfectly Replicate Writing Skills](https://github.com/zrh091110225/perfectly-replicate-writing-skills), изначально созданного [JinDaGe](https://jindage.com). Это отдельный, самостоятельно поддерживаемый скилл: он адаптирует исходный фреймворк под русский язык (ручная лемматизация, русские стоп-слова, пороги в словах, маркеры стиля бизнес-ТЗ 1С) и не является зеркалом оригинала.

## Обзор

Скилл берёт 3+ документа автора и, пройдя 4-фазный глубокий анализ, выдаёт два результата:

- **Результат A: Переносимый промпт стиля** — самодостаточная стилистическая инструкция, работающая с любой LLM (Claude, ChatGPT и др.)
- **Результат B: Persona-подскилл** — устанавливаемый скилл персоны для Claude Code

Инструкции скилла написаны на английском (экономия токенов), но **вывод** (style card, persona, промпт стиля) генерируется **на языке автора**. Для русскоязычного автора весь вывод — на русском.

## Фреймворк анализа: 7+1 измерение

| Измерение | Что измеряется | Режим анализа |
|-----------|----------------|---------------|
| 1. Лексика | частоты слов, фингерпринт-слова, коллокации, лексическое разнообразие | параллельно |
| 2. Синтаксис | средняя длина предложения, доли типов конструкций, пунктуационный fingerprint, ритм абзацев | параллельно |
| 3. Тональность | индекс разговорности, волатильность длины предложений, формальность, определённость | параллельно |
| 4. Дискурс | типы начал/концов, ритм абзацев, логический поток | последовательно |
| 5. Риторика | плотность метафор, параллелизм, риторические вопросы, соотношение конкретного/абстрактного | параллельно |
| 6. Эмоция | распределение полярности, эмоциональная дуга, маркеры позиции | параллельно |
| 7. Перспектива | тематические кластеры, распределение местоимений, система образов, ценностные слова | параллельно |
| 8. Адаптация к формату | структурная инерция, соответствие жанрам, рекомендация формулы | последним |

## 4-фазный рабочий процесс

### Фаза 0: Ingestion (приём корпуса)
- Принимает ≥3 документа (≥2 000 слов суммарно)
- Идеал: ≥10 документов / ≥10 000 слов
- Автоматическая дедупликация, очистка, статистика
- Объём считается в **словах** для русского и английского; в **символах** только для китайского

### Фаза 1: Анализ по 7+1 измерениям
- Систематическое измерение 7 измерений (смешанный параллельный + последовательный режим)
- Оценка адаптации к формату — последней

### Фаза 2: Синтез портрета стиля
- Дистилляция 3–5 ключевых выводов по каждому измерению
- Кросс-валидация для извлечения 3–5 «пищевых генов» (writing genes)
- Генерация запрещённого списка из 5–10 пунктов

### Фаза 3: Двойной вывод
- **Результат A**: переносимый промпт стиля
- **Результат B**: persona-подскилл

### Фаза 4: Слепой тест
- Генерация 2 тестовых текстов по **500–700 слов** (≈3 500–5 000 символов для русского)
- Оценка каждого по всем 7 измерениям против оригинала
- Проходной порог — композитное совпадение >70% (оценивается на полном объёме 500–700 слов)

## Использование

### Установка как скилл Claude Code

```bash
# Клонируем проект
git clone https://github.com/zhihus/perfectly-replicate-writing-skills-ru.git
cd perfectly-replicate-writing-skills-ru

# Устанавливаем скилл
cp -r SKILL.md ~/.claude/skills/perfectly-replicate-writing-skills-ru/
cp -r references ~/.claude/skills/perfectly-replicate-writing-skills-ru/
```

После этого запускаем в Claude Code:

> «Проанализируй стиль автора по этим статьям»
> «Склонируй стиль письма этого автора»
> «Напиши статью об эффективности в стиле [автор]»

### Использование как самостоятельный инструмент

Ручной прогон 4-фазного рабочего процесса:
1. Соберите ≥3 документа целевого автора
2. Проанализируйте по 7+1 измерениям
3. Синтезируйте портрет стиля
4. Сгенерируйте промпт стиля и persona-подскилл

## Ключевые принципы

1. **Признак, появляющийся 3+ раза, — реальный стилистический сигнал** — один раз это импровизация, три раза — стиль
2. **Сохранять противоречия** — не сглаживать непоследовательность автора
3. **Быть конкретным** — «средняя длина предложения 12 слов, 30% предложений короче 8 слов» полезно; «любит короткие предложения» — нет
4. **Запрещённый список важнее позитивных признаков** — границы стиля часто определяются тем, что автор *никогда* не делает
5. **Не додумывать** — не выдумывать биографию автора; не выдавать общие советы по письму за уникальный стиль
6. **Не сглаживать несовершенства** — неуклюжие формулировки, причуды и шероховатости — маркеры идентичности
